# Parshva Shah — Personal Portfolio & 3D Project Universe

> **Live Website:** [https://parshvashah2008.github.io/parshva-portfolio/](https://parshvashah2008.github.io/parshva-portfolio/)

An immersive, interactive personal portfolio and digital universe built with **React 19**, **Three.js / React Three Fiber**, **Tailwind CSS v4**, and **Framer Motion**, inspired by the spatial exploration of Vadim Carazan and the haute-editorial aesthetics of Suho Studio.

---

## 🏛️ Architecture & Sections

1. **Home / Cinematic Introduction**: High-contrast typography (`Instrument Serif`, `Manrope`, `Geist Mono`), live status indicator, and real-time luminance-mapped portrait particle matrix.
2. **The 3D Project Universe**: Spatial WebGL constellation with organic drifting nodes, depth-of-field, mouse parallax, and dual-mode toggle between **3D Universe** and **Editorial List**.
3. **Dedicated Case Studies**: 16-point architectural breakdowns for production software (FastAPI WhatsApp FSM, JEE STEM solver, Scholars Hub, MediaPipe computer vision).
4. **About Me**: Engineering journey at **KJ Somaiya School of Engineering (BTech 2026–2030)**, commercial freelance practice, photography, and product philosophy.
5. **Experience & Verified Credentials**:
   - Academic & independent practice timeline
   - **8 Forage Industry Job Simulations** (Goldman Sachs, J.P. Morgan, Tata, Skyscanner, British Airways, Deloitte, Siemens)
   - **18 Anthropic Claude Credentials** with full Skilljar verification links
   - **Google for Education** Gemini Certified Student credential
   - Fullscreen **Interactive Certificate Lightbox Viewer** with direct PDF document downloads
6. **Systems Architecture & Toolkit**: Categorized capabilities with proficiency badges and interactive 3D Orbit view.
7. **Computational Playground**: Four playable in-browser experiments (Gravitational Particle Vortex, Harmonic Audio Synth, Cybernetic Noise, Kinetic Typography).
8. **Field Notes & Technical Writing**: Editorial long-form essays on state machines, LLM routing, and computer vision.
9. **Contact & Collaboration**: Direct communication channels, copy email action, accessible contact form, and live Mumbai (IST) clock.

---

## 🛠️ Tech Stack

- **Framework**: React 19, Vite
- **3D & Graphics**: Three.js, @react-three/fiber, @react-three/drei
- **Motion & Physics**: Framer Motion, GSAP, Lenis Smooth Scroll
- **Typography**: Instrument Serif, Cormorant Garamond, Manrope, Geist Mono
- **Deployment**: GitHub Pages via GitHub Actions

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/parshvashah2008/parshva-portfolio.git
cd parshva-portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
npm run preview
```
